# Caos Total

Party game multiplayer 2D para 3 a 5 jogadores.

## Requisitos
- Node.js 20 ou superior

## Executar
```bash
npm install
npm start
``

Abra http://localhost:3000 em cada dispositivo conectado à mesma rede. Para jogar pela internet, hospede o servidor em uma plataforma que aceite WebSockets.

## Controles
- Celular: joystick virtual e botão de impulso.
- Computador: WASD ou setas; espaço para impulso.
